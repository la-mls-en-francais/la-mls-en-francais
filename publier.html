Mode d’emploi

Comment publier

Depuis le téléphone : va sur la page Écrire, colle ton article, appuie sur Aperçu, puis Copier. Envoie ce texte pour qu’il apparaisse pour tout le monde.

Le site s’adapte au téléphone et à l’ordinateur : gros boutons, menu ☰, textes lisibles.

Pour que le site ait une vraie adresse internet : un jour, sur un ordinateur, glisse le dossier folio sur Netlify Drop. Gratuit. Pas besoin de coder.

Méthode 1 — Pages images (lecteur Folio)

Exportez chaque page de votre magazine en JPG ou PNG (depuis InDesign, Canva, Affinity, ou un PDF via aperçu / Acrobat). Placez-les dans img/, puis ajoutez une entrée dans data/magazines.js :

{
  id: "mon-magazine-01",
  title: "Mon magazine",
  issue: "N° 01",
  category: "Culture",
  date: "Août 2026",
  pages: 36,
  featured: true,
  cover: "img/mon-magazine.jpg",
  excerpt: "Une phrase d’accroche.",
  description: "Le texte de l’édito.",
  mode: "folio",
  images: [
    "img/mon-magazine.jpg",
    "img/mon-magazine-p2.jpg",
    "img/mon-magazine-p3.jpg"
  ]
}

Le lecteur tourne ensuite ces pages comme un vrai magazine. Plus vous ajoutez d’images, plus le numéro est long.

Méthode 2 — Intégrer un flipbook Heyzine

Créez le magazine sur heyzine.com, récupérez le lien public (ou le code d’intégration), puis déclarez :

{
  id: "catalogue-automne",
  title: "Catalogue automne",
  issue: "2026",
  category: "Catalogue",
  date: "Septembre 2026",
  pages: 80,
  cover: "img/catalogue.jpg",
  excerpt: "Le nouveau catalogue.",
  description: "Publié via Heyzine, lu ici.",
  mode: "heyzine",
  embedUrl: "https://heyzine.com/flip-book/xxxxxxxx.html"
}

Le lecteur Folio bascule alors en iframe plein cadre : vos visiteurs restent sur votre site, le feuilletage est celui de Heyzine.

Méthode 3 — HTML exporté par Heyzine

Sur les formules payantes, Heyzine permet de télécharger le flipbook en HTML autonome. Placez ce dossier dans le site (par exemple revues/automne-2026/) et pointez embedUrl vers revues/automne-2026/index.html. Vous n’êtes plus dépendant de leur cloud.

Publier un article déjà écrit

Ouvrez data/articles.js. Chaque texte est un objet. Collez votre article dans body en HTML simple (<p>, <h2>, éventuellement <blockquote> ou <em>).

{
  id: "titre-de-mon-article",
  title: "Titre de mon article",
  category: "Culture",
  date: "29 août 2026",
  readTime: "6 min",
  cover: "img/ma-photo.jpg",
  excerpt: "Deux phrases pour donner envie.",
  magazine: "horizon-12",
  body: `
    <p class="chapo">Chapô optionnel.</p>
    <p>Premier paragraphe de votre texte déjà écrit.</p>
    <h2>Intertitre</h2>
    <p>Suite de l’article…</p>
  `
}

magazine est optionnel : s’il correspond à l’id d’un numéro, un lien « Lire le magazine » apparaît en bas de l’article. Pour un texte indépendant, enlevez simplement cette ligne.

Astuce : depuis Word, copiez le texte, puis entourez chaque paragraphe de <p>…</p>. Pas besoin de CMS.

Personnaliser l’identité

Changez le nom « Folio » dans les pages HTML, les couleurs dans css/style.css (--ink, --paper, --gold), et remplacez les images d’exemple. Ajoutez votre domaine et un favicon quand le site est en ligne.
